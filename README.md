# 极简记账工具

一个用**纯 Python**（不需要安装任何第三方库）写的命令行记账小工具，用来练手「写代码 → 提交到 Git → 上传 GitHub」的完整流程。

## 功能
- 记一笔（金额、分类、备注）
- 查看所有记录
- 按分类统计花费
- 删除一笔

## 怎么运行
1. 你需要装好 Python（你已经有了）。
2. 在终端进入本文件夹，运行：
   ```
   python main.py
   ```
3. 按菜单输入 1-5 操作。

## 项目结构（每个文件是干嘛的）
- `main.py`：程序入口，负责菜单和用户输入（你能直接运行它）。
- `expense.py`：核心逻辑（记账、统计），和界面分开，方便测试和复用。
- `tests/test_expense.py`：自动化测试，保证核心逻辑没写错。
- `README.md`：就是本文件，说明项目。
- `.gitignore`：告诉 Git 哪些文件不用上传。
- `LICENSE`：开源协议（MIT），说明别人可以用你的代码。

## 怎么跑测试
```
python -m unittest tests/test_expense.py
```
